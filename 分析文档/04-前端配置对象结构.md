# 04 · 前端配置对象结构

> AIPKit 的每个聊天实例通过 DOM 属性 `data-config`（JSON 字符串）接收全部配置。
> 本文汇总从 `public-main.bundle.js` 反推出的配置字段。**字段名为静态确认，具体值待实测。**

---

## 1. 配置入口

```html
<div class="aipkit_chat_container"
     data-bot-id="123"
     data-config='{ ...JSON... }'>
```

初始化解析（`public-main.bundle.js` 末尾）：

```js
let t = el.getAttribute("data-bot-id");
let a = el.getAttribute("data-config");
let i = JSON.parse(a);
if (t) i.botId = t;                          // data-bot-id 覆盖
window.aipkit_current_post_id = i.postId || 0;
```

## 2. 核心字段（已确认）

### 2.1 连接与身份

| 字段 | 类型 | 说明 | 证据 |
|------|------|------|------|
| `ajaxUrl` | string | `admin-ajax.php` 绝对 URL | `createEventSource` 校验 |
| `nonce` | string | `_ajax_nonce` 值 | 所有请求携带 |
| `botId` | string/number | 机器人 ID | 覆盖自 `data-bot-id` |
| `postId` | number | WordPress 文章 ID | `window.aipkit_current_post_id` |
| `provider` | string | `OpenAI` / `Claude` / `Google` / `OpenRouter` / `xAI` | 分支判断 |
| `sessionId` | string | 访客会话 ID（可选，前端也自生成） | `getSessionId` |

### 2.3 图片命令

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `imageTriggers` | string | `"/image"` | 触发词，逗号分隔，须以 `/` 开头 |
| `imageUploadEnabledUI` | bool | — | 图片上传 UI |

触发逻辑：
```js
const triggers = (cfg.imageTriggers || "/image").toLowerCase()
    .split(",").map(s=>s.trim()).filter(s=>s.length>0 && s.startsWith("/"));
// 匹配 "消息以 trigger+空格 开头" 或 "消息 == trigger"
```

```js

  nonce: "0c69ef9c1b",           // X-WP-Nonce
  purchaseNonce: "d99ec90d7c",
  mayBuy: true,
  lang: "es",
  i18n: {
    modal_title, modal_subtitle, balance_label, buy_button_default,
    quota_inline_text, quota_inline_btn, footer_dual, thanks_balance,
    restore_link, support_title, ... // 100+ 条西语文案

```

**关键 i18n 模板**：

- `quota_inline_text` = `"Tu saldo de tokens se ha agotado."`
- `modal_subtitle` = 含 HTML 的多条说明（安全/可视化/免费/支持）

## 8. 配置获取的替代途径

由于 `data-config` 是页面渲染时注入的，**2API 代理无法直接"请求"配置**。可选方案：

1. **抓取页面 HTML**，正则提取 `data-config='...'`（推荐）
2. **调用 nonce 端点**：`action=aipkit_get_frontend_chat_nonce` 只能拿 nonce，拿不到完整配置
3. **从 bundle 反推默认值**（本文档已做）

> 建议代理侧实现「HTML 配置提取器」：GET 聊天页 → 正则 `data-config="([^"]+)"` → JSON.parse。
