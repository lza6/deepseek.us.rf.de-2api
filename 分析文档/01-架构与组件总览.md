## 2. 域名关系

| 域名 | 角色 |
|------|------|
| `deepseek.de` | **主站**（德语） |
| `deepseek.es` | **镜像/西班牙语站**（本次抓取目标） |

**证据**：`admin-ajax.php` 中一段 Polylang XHR：

```js
xhr.open("GET", "https://deepseek.de/wp-admin/admin-ajax.php?action=pll_xdata_get&redirect=https%3A%2F%2Fdeepseek.es%2F&nonce=0a6dca9b00", true);
// → 成功后跳转 https://deepseek.es/wp-admin/admin-ajax.php?action=pll_xdata_set&key=...
```

说明两站共享后端逻辑，`pll_xdata_*` 用于在语言/域名间传递状态。AIPKit 资源 URL 也统一指向 `deepseek.de`（见 `aipkit-public-main-js-before`），实际由 CDN 或跨域加载。

## 3. AI 数据流（核心）

```
① 用户输入消息
       │
       ▼
② aipkit_chatUI_handleChatFormSubmission / handleFormSubmission
       │
       ├─(若有图片/文件)→ 收集 imageInputs / fileContext
       │
       ▼
③ POST admin-ajax.php  action=aipkit_cache_sse_message
       body: message, _ajax_nonce, bot_id, image_inputs, user_client_message_id
       ← 返回 { success:true, data:{ cache_key } }
       │
       ▼
④ new EventSource(
       admin-ajax.php?action=aipkit_frontend_chat_stream
         &cache_key=<key>&bot_id=<id>&session_id=<guest_uuid>
         &conversation_uuid=<conv>&post_id=<pid>&_ajax_nonce=<nonce>
         [+ previous_openai_response_id] [+ frontend_web_search_active]
         [+ frontend_google_search_grounding_active] [+ 向量库上下文参数]
   )
       │
       ▼
⑤ SSE 事件流（服务端逐帧推送）
   message_start → (onmessage:delta) → status / citations /
   grounding_metadata / openai_response_id / display_form_event /
   warning → done | error(quota_notice)
       │
       ▼
⑥ 前端渲染 markdown、引用、表单、配额通知
```

**关键设计**：消息内容不入 GET query（防日志泄露），先经 POST 缓存为 `cache_key`，SSE 只传 key。这是 AIPKit 的安全设计。

## 4. AIPKit 前端架构特征

AIPKit 不使用现代打包框架，而是**把几百个函数挂到 `window` 全局**，形成隐式模块系统：

```
window.aipkit_*              → 全局命名空间
window.aipkit_chatUI_*       → UI 操作函数
window.aipkit_public_*       → 公开 API
window.chatImageUpload       → 图片上传子模块
window.aipkitChatFileUpload  → 文件上传子模块
window.aipkitTtsState        → TTS 状态
```

功能分包按需动态加载（`<script async>` 注入），加载器逻辑：

```js
const FEATURES = {
  sidebar:       { urlKeys:["chatSidebar","sidebar"],       isReady:()=>typeof window.aipkit_initConversationSidebar=="function" },
  stt:           { urlKeys:["chatStt","stt"],               isReady:()=>typeof window.aipkit_chatUI_handleVoiceInputAction=="function" },
  uploads:       { urlKeys:["chatUploads","uploads"],       isReady:()=>!!(window.chatImageUpload?.init && window.aipkitChatFileUpload?.processFile) },
  tts:           { urlKeys:["chatTts","tts"],               isReady:()=>typeof window.aipkit_handlePlayAction=="function" && !!window.aipkitTtsState },
  starters:      { urlKeys:["chatStarters","starters"],     isReady:()=>typeof window.aipkit_initConversationStarters=="function" },
  imageCommand:  { urlKeys:["chatImageCommand","imageCommand"], isReady:()=>typeof window.aipkit_chatUI_handleImageGeneration=="function" },
  realtime:      { urlKeys:["chatRealtime","realtime"],     isReady:()=>typeof window.aipkit_initRealtimeVoiceAgent=="function" },
  pdf:           { urlKeys:["chatPdf","pdf"],               isReady:()=>typeof window.aipkit_chatUI_downloadTranscriptActionPdf=="function" },
};
```

资源 URL 白名单在 `aipkit-public-main-js-before` 中硬编码（`window.aipkitPublicAssetUrls`），指向 `deepseek.de/wp-content/plugins/gpt3-ai-content-generator/dist/js/*.bundle.js?ver=2.4.21`。

## 5. 每个聊天实例的初始化

容器 DOM：

```html
<div class="aipkit_chat_container"
     data-bot-id="123"
     data-config='{"ajaxUrl":"...","nonce":"...","botId":"123","provider":"...", ...}'>
  ...
</div>
```

初始化序列（`public-main.bundle.js` 末尾）：

```js
let t = el.getAttribute("data-bot-id");
let a = el.getAttribute("data-config");
let i = JSON.parse(a);           // ← 全部配置来源
if (t) i.botId = t;
// ... 写入 window.aipkit_current_post_id 等全局
```

`data-config` 是**唯一的配置入口**，字段详见 [04-前端配置对象结构](./04-前端配置对象结构.md)。

## 6. DEEPSEEK.DE 自研层与 AIPKit 的耦合点

| 自研脚本 | 依赖的 AIPKit 能力 | 目的 |
|---------|------------------|------|
| `buy-tokens.js` | 读取 `.aipkit_chat_container[data-bot-id]`；监听 `aipkit:messageReceived` / `aipkit:messageError` | 显示余额、配额耗尽时弹出购买 |
| `deepseek-chat-button-ux-js-after` | 调用 `window.aipkit_frontendApiRequest("aipkit_get_conversations_list"/"aipkit_delete_single_conversation")` | 清空历史、下载对话 |
| `deepseek-chat-fullscreen-sidebar-js-after` | 读取 `data-bot-id`；调用 `admin-ajax.php?action=dsbx_get_bot_model` | 显示模型徽章、管理侧栏状态 |
| `aipkit-public-main-js-after` | 包装 `window.aipkit_frontendApiRequest` 与 `aipkit_chatUI_cacheSseMessage` | nonce 过期自动刷新重试 |

**自研层的关键 hack**：`buy-tokens.js` 中 `rehydrateQuotaMessages` 把 AIPKit 用 `textContent` 转义的配额消息重新按 HTML 解释，使 `<a href="#dsgt-buy-tokens">` 变成真链接，并自动弹出购买弹窗。

## 7. 与"2API"的关系

deepseek.es **不是** OpenAI 兼容 API。它的 AI 能力被 AIPKit 封装在 WordPress AJAX/SSE 后面。

要构建 2API 代理，本质是：
1. 逆向 SSE 协议（[03](./03-SSE流式协议详解.md)）
2. 在代理侧把 OpenAI `/v1/chat/completions` 翻译为 AIPKit 的两步调用
3. 把 SSE 事件流翻译回 OpenAI `chat.completion.chunk` 格式

详见 [07-2API代理实现指南](./07-2API代理实现指南.md)。
