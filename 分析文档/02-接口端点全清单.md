## B. WordPress REST 端点

### B.1 DEEPSEEK.DE 代币系统 `dsgt/v1`

Base URL：`https://deepseek.es/wp-json/dsgt/v1/`（来自 `dsgt-buy-js-before` 的 `restUrl`）

| 端点 | 方法 | 参数 | 响应 | 状态 |
|------|------|------|------|------|
| `balance` | GET | `bot_id`(可选), `_t`(缓存破坏) | `{balance:number, free:{remaining:number}}` | 静态确认 ★ |
| `packages` | GET | — | `{packages:{key:{label,price,currency}}}` | 静态确认 ★ |
| `create-order` | POST | JSON `{package_key}` | `{order_id}` 或 `{error}` | 静态确认 |
| `capture-order` | POST | JSON `{paypal_order_id}` | `{ok, balance, tokens_granted}` 或 `{error}` | 静态确认 |
| `resend-recovery` | POST | JSON `{email, lang}` | `{success}` | 静态确认 |
| `support` | POST | JSON `{name, email, message}` | `{ok}` | 静态确认 |

**请求头要求**：
- `X-WP-Nonce: <dsgtConfig.nonce>` — 必需，否则被当匿名（注释明确说明）
- `credentials: same-origin`（携带 WP 认证 cookie）
- `Content-Type: application/json`（POST）

**配置来源** `window.dsgtConfig`：
```js
{
  restUrl: "https://deepseek.es/wp-json/dsgt/v1/",
  nonce: "0c69ef9c1b",
  purchaseNonce: "d99ec90d7c",
  mayBuy: true,
  lang: "es",
  i18n: { ...100+ 条西语文案 }
}
```

## C. SSE 端点（核心）

### C.1 前端聊天流

```
GET /wp-admin/admin-ajax.php?action=aipkit_frontend_chat_stream
    &cache_key=<缓存键>
    &bot_id=<机器人ID>
    &session_id=<访客UUID>
    &conversation_uuid=<会话UUID>
    &post_id=<文章ID>              (可选)
    &previous_openai_response_id=  (仅 OpenAI + 会话状态)
    &frontend_web_search_active=true   (可选)
    &frontend_google_search_grounding_active=true (仅 Google)
    &_ts=<时间戳>                  (缓存破坏)
    &_ajax_nonce=<nonce>
    [+ 向量库上下文参数]
Accept: text/event-stream
```

**响应事件类型**（详见 [03 文档](./03-SSE流式协议详解.md)）：
`message_start`、`openai_response_id`、`grounding_metadata`、`status`、`citations`、`display_form_event`、`warning`、`done`、`error`；默认 `onmessage` 承载 `delta`。
