## 1. 上游协议总览（已验证）

```
① CfSolver 求解 Turnstile
   GET  http://127.0.0.1:8001/turnstile?url=https://deepseek.es/&sitekey=0x4AAAAAADlLZ3ljqZP6cQwq&action=chat
   → {task_id}  → 轮询 /result?id= → {status:"success", value:"<709字符token>"}

② 兑换安全 Cookie
   POST /wp-admin/admin-ajax.php  action=deepseek_ts_verify&token=<token>
   → {ok:true}  + Set-Cookie: dsts_ok=1; dsts=<...>

③ 刷新 nonce
   POST action=aipkit_get_frontend_chat_nonce&bot_id=<id>
   → {success:true, data:{nonce}}

④ 缓存消息换 cache_key
   POST action=aipkit_cache_sse_message&message=<text>&_ajax_nonce=<nonce>&bot_id=<id>
   → {success:true, data:{cache_key}}

⑤ SSE 流
   GET  ?action=aipkit_frontend_chat_stream&cache_key=..&bot_id=..&session_id=..&conversation_uuid=..&_ajax_nonce=..&_ts=..
   SSE: event: message_start → (默认 message: {"delta":..}) × N → event: done
```

---

## 2. 关键技术约束（E2E 发现）

| 约束 | 说明 | 应对 |
|------|------|------|
| **必须过 Turnstile** | 无 `dsts_ok` cookie 时 SSE 返回 `{"error":"Sicherheitspruefung erforderlich.","ts_required":true}` | 集成 cf_solver 求解并用 `deepseek_ts_verify` 兑换 |
| **CF 求解耗时 ~45-65s** | Turnstile managed 模式需浏览器 | 异步预取 + 池化（见 §5） |
| **token 一次性** | `cache_key` 消费后失效（再次用返回 `Message not found in cache.`） | 每次请求新 cache_key |
| **cookie 有时效** | `dsts_ok` 会过期（设计上通过 Turnstile 后台续期） | 缓存 cookie + 失效自愈（见 §5.3） |
| **必须走代理** | 本机直连 deepseek.es 返回 302（网络环境限制）；需 `HTTPS_PROXY` | 代理侧配置出口代理 |
| **网络/TLS** | Windows 证书吊销检查离线，curl 需 `--ssl-no-revoke` | Node/Python 侧用宽松 TLS 或修 CA |

### 4.3 Turnstile 求解客户端

```python
import httpx, asyncio

SOLVER = "http://127.0.0.1:8001"
SITEKEY = "0x4AAAAAADlLZ3ljqZP6cQwq"
TARGET = "https://deepseek.es/"

async def solve_turnstile(url=TARGET, sitekey=SITEKEY, action="chat", timeout=90):
    async with httpx.AsyncClient(timeout=timeout) as c:
        r = await c.get(f"{SOLVER}/turnstile",
                        params={"url": url, "sitekey": sitekey, "action": action})
        r.raise_for_status()
        task = r.json()["task_id"]
        deadline = asyncio.get_event_loop().time() + timeout
        while asyncio.get_event_loop().time() < deadline:
            await asyncio.sleep(2)
            j = (await c.get(f"{SOLVER}/result", params={"id": task})).json()
            if j.get("status") == "success":
                return j["value"]
            if j.get("status") == "error":
                raise RuntimeError(f"求解失败: {j}")
        raise TimeoutError("Turnstile 求解超时")
```

### 4.4 兑换安全 Cookie

```python
async def verify_ts(client, token):
    r = await client.post(AJAX, data={"action": "deepseek_ts_verify", "token": token})
    j = r.json()
    if not j.get("ok"):
        raise RuntimeError(f"安全校验失败: {r.status_code} {r.text}")
    return client.cookies        # 含 dsts_ok=1
```

## 5. 上游客户端实现要点

### 5.1 完整的认证刷新流程

```
首次 / cookie 失效时：
   token = solve_turnstile()          # ~45-65s
   verify_ts(token)                    # → dsts_ok cookie
   刷新 nonce                          # aipkit_get_frontend_chat_nonce
```

### 5.2 SSE 解析（已验证的规范做法）

```python
async def chat(client, bot_id, nonce, message) -> AsyncIterator[str]:
    # 1) 缓存消息
    ck = await client.post(AJAX, data={
        "action": "aipkit_cache_sse_message", "message": message,
        "_ajax_nonce": nonce, "bot_id": bot_id,
    })
    cache_key = ck.json()["data"]["cache_key"]

    # 2) SSE
    sid = str(uuid.uuid4())
    params = {
        "action": "aipkit_frontend_chat_stream", "cache_key": cache_key,
        "bot_id": bot_id, "session_id": sid, "conversation_uuid": sid,
        "_ajax_nonce": nonce, "_ts": int(time.time() * 1000),
    }
    async with client.stream("GET", AJAX, params=params,
                             headers={"Accept": "text/event-stream"}) as r:
        event = "message"
        async for line in r.aiter_lines():
            if line.startswith("event:"):
                event = line[6:].strip()
            elif line.startswith("data:"):
                data = json.loads(line[5:].strip())
                # 默认 message 事件承载 delta
                if event == "message" and isinstance(data, dict) and "delta" in data:
                    yield data["delta"]
                elif event == "done":
                    break
                elif event == "error":
                    if data.get("ts_required"):
                        raise TSRequired()   # 触发重新求解
                    raise UpstreamError(data.get("error"))
```

> **关键**：SSE 事件以**空行**分隔。无 `event:` 行的数据块是默认 `message` 事件（承载 `delta`）。
> 不能简单地"沿用上一个 event 名"——这会把 delta 误标成 `message_start`。

### 5.3 Cookie 与 Token 池

```
CookiePool:
  - 键：出口 IP
  - 值：{ dsts_ok, dsts, created_at, ttl }
  - TTL：保守设 30 分钟（实际更长，但保守刷新）
  - 失效信号：SSE 返回 ts_required → 标记失效 → 重新求解

TokenPool（可选，预取）:
  - 空闲时预取 Turnstile token
  - 请求到来直接兑换，省 ~50s
  - 限流保护：求解器串行/低并发
```

### 5.4 会话映射

```
OpenAI 会话 (下游)            →  deepseek.es 会话 (上游)
─────────────────────────────────────────────────────
- 无状态 (每请求独立)          →  新建 session_id / conversation_uuid
- 需多轮上下文                  →  固定 conversation_uuid（上游按此查历史）
- "user" 字段                  →  固定 session_id（如需跨会话身份）
```

> 上游多轮上下文：非 OpenAI provider 由服务端按 `conversation_uuid` 组装历史；
> provider=DeepSeek 时（本站），对话历史**由服务端按会话 UUID 维护**，代理只需保持同一 UUID。

## 6. 协议翻译（OpenAI ↔ AIPKit）

### 6.1 `/v1/chat/completions`（流式）

```python
async def openai_stream(req):
    # 1) 取 messages 最后一条 user 内容
    prompt = last_user_content(req.messages)
    # 2) 确保认证（cookie + nonce）
    client, bot_id, nonce = await ensure_authed()
    # 3) 发到上游
    cid = f"chatcmpl-{uuid.uuid4().hex}"
    created = int(time.time())
    async for delta in chat(client, bot_id, nonce, prompt):
        chunk = {
            "id": cid, "object": "chat.completion.chunk",
            "created": created, "model": req.model,
            "choices": [{"index": 0, "delta": {"content": delta}, "finish_reason": None}],
        }
        yield f"data: {json.dumps(chunk)}\n\n"
    # 结束帧
    yield f'data: {json.dumps({... "delta": {}, "finish_reason": "stop" ...})}\n\n'
    yield "data: [DONE]\n\n"
```

### 6.3 错误映射

| 上游 | OpenAI |
|------|--------|
| `ts_required` | 内部重试（重新求解），对下游透明 |
| `Sicherheitspruefung erforderlich.` | 同上 |
| `quota_notice` | HTTP 429，`{"error":{"type":"rate_limit_error"}}` |
| `Message not found in cache.` | 内部重试（新 cache_key） |
| SSE `error` 其它 | HTTP 502 |
