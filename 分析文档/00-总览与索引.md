## 0. 一句话结论

`deepseek.es` 是一个 **WordPress 站点**，其 AI 聊天能力由第三方商业插件 **AIPKit（`gpt3-ai-content-generator` v2.4.21，作者 Senol Sahin）** 提供，站点运营方（DEEPSEEK.DE / deepseek.es）在其上叠加了自研补丁层（前缀 `dsgt_` 代币购买、`dsbx_` 界面增强、`pll_` 多语言）。

**它本身不是"OpenAI 兼容 API"，而是一个 WordPress AJAX + SSE 形态的前端聊天应用。** 所有 AI 调用都经过服务端 `admin-ajax.php` 中转，密钥不会暴露给前端。要把它包装成 2API，需要逆向并复刻其 **frontend chat stream SSE 协议** 与 **会话/配额管理**。

## 3. 关键结论速览

### 3.1 技术栈
- **CMS**：WordPress + Polylang（多语言，主域 `deepseek.de`，镜像 `deepseek.es`）
- **AI 插件**：AIPKit `gpt3-ai-content-generator` v2.4.21
- **支付**：PayPal SDK（代币购买）
- **安全**：Cloudflare Turnstile（`api.js`）+ WordPress nonce
- **监控**：Cloudflare Insights RUM
- **前端框架**：原生 JS（AIPKit 自研 window 全局函数架构）+ Preact（index.min.js 内联）

### 3.2 AI Provider 支持（AIPKit 能力）
从 `public-main.bundle.js` 确认支持：`OpenAI`、`Claude` (Anthropic)、`Google` (Gemini)、`OpenRouter`、`xAI` (Grok)。

### 3.3 聊天走 SSE，不走 OpenAI 格式
- 传输：`EventSource`（GET）+ `text/event-stream`
- 端点：`/wp-admin/admin-ajax.php?action=aipkit_frontend_chat_stream`
- 消息先经 `action=aipkit_cache_sse_message` 缓存换取 `cache_key`，再用 `cache_key` 建立 SSE

### 3.4 会话与身份
- 访客身份：`localStorage.aipkit_guest_uuid` → 作为 `session_id` 上报
- 会话 ID：`window.aipkit_current_conversation_uuid`
- 前端 nonce：`_ajax_nonce`（可自动刷新）

### 3.5 配额模型（自定义层）
- **每日免费额度** + **付费代币余额** 双轨制
- `dsgt` REST：`/wp-json/dsgt/v1/balance` 返回 `{balance, free:{remaining}}`
- 免费额度优先消耗；余额与浏览器绑定（非账号）
